# WANDER.ph

WANDER.ph is a responsive travel landing page for discovering Philippine destinations, browsing tour packages, reading travel stories, and submitting booking requests.

The frontend is built with React, TypeScript, Vite, and Tailwind CSS. Newsletter subscriptions and booking requests are stored in Cloud Firestore through the Firebase Web SDK.

## Features

- Responsive travel landing page
- Destination search and filtering
- Destination detail views
- Tour package browsing
- Blog post detail views
- Booking request form
- Newsletter subscription form
- Firestore integration for form submissions
- Mobile navigation and responsive layouts

## Requirements

- Node.js 18 or newer
- npm
- A Firebase project with Cloud Firestore enabled

## Installation

Install the dependencies from the project directory:

```powershell
npm install
```

If dependencies are already installed and `package.json` has not changed, this step can be skipped.

## Firebase configuration

1. Open the [Firebase Console](https://console.firebase.google.com/).
2. Create or select a Firebase project.
3. Add a Web app in **Project settings**.
4. Copy `.env.example` to `.env`.
5. Replace the placeholder values in `.env` with the Firebase Web App configuration values.

Example:

```env
VITE_FIREBASE_API_KEY=your-api-key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your-project-id
VITE_FIREBASE_STORAGE_BUCKET=your-project.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=your-messaging-sender-id
VITE_FIREBASE_APP_ID=your-app-id
```

Never commit `.env`, Firebase service-account JSON files, private keys, or other credentials. These files are ignored by `.gitignore`.

For Firestore collections and security rules, see [FIREBASE_SETUP.md](FIREBASE_SETUP.md).

### Firestore collections

The application writes to these collections:

- `newsletter_subscribers`: `email`, `createdAt`
- `booking_requests`: `destination`, `travelDate`, `guests`, `fullName`, `phone`, `email`, `notes`, `createdAt`

The `createdAt` value is generated by the application with Firestore `serverTimestamp()`.

## Development

Start the Vite development server:

```powershell
npm run dev
```

Open the local URL printed in the terminal, usually `http://localhost:5173/`.

If the default port is busy, Vite automatically selects another available port.

## Production build

Create a production build:

```powershell
npm run build
```

Preview the production build locally:

```powershell
npm run preview
```

The generated files are placed in `dist/`. The Vite configuration uses `vite-plugin-singlefile`, so the production HTML includes the bundled JavaScript and CSS.

## Deployment notes

Set the Firebase environment variables in the hosting provider's environment settings before deploying. Do not upload `.env` or Firebase admin credentials. After deployment, verify that the Firestore security rules allow the required public `create` operations while keeping read, update, and delete operations protected.
